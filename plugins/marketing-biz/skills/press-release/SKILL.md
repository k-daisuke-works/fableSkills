# プレスリリース作成

メディアに取り上げられ、読者に伝わるプレスリリースを作るスキル。

## 大原則

**プレスリリースは広告ではなくニュースの提供。** 記者が「これは記事になるか」で判断する以上、自社が言いたいことではなく、社会・読者にとっての新規性から組み立てる。ニュース価値が弱いままリリースを書いても配信費の無駄なので、価値が弱い場合はその旨を正直に伝え、価値の作り方から提案する。

## 手順

### 1. ニュース価値の診断

発表内容を以下でチェックし、強い角度を見つける:

- **新規性**: 業界初・日本初・新カテゴリ（※「初」は根拠必須。景表法リスク）
- **社会性・時事性**: 社会課題・トレンド（法改正、AI、人手不足等）との接続
- **意外性・数字**: 直感に反する調査結果、インパクトのある実績数値
- **地域性・人間性**: ローカルメディア向けの地元性、創業ストーリー

弱い場合の価値の作り方: 自社調査データを添える（調査リリースは取り上げられやすい）、社会文脈と結びつける、実績・事例を主役にする。

### 2. 構成（逆ピラミッド）

記者は最初の数行で読むかを決める。重要情報から順に:

```
タイトル（30〜40文字目安）: 「誰が」「何を」+ニュース価値。社名より価値を先に
サブタイトル: 補足の具体（数字・日付）
リード（最初の段落）: 5W1H をここで完結させる。これだけで記事が書ける状態に
本文:
  背景（なぜ今これが必要か = 社会文脈）
  発表内容の詳細（機能・価格・提供開始日・対象）
  代表者・担当者コメント（人の声。想いと今後の展望）
  今後の予定
会社概要（ボイラープレート）/ 本件の問い合わせ先（広報連絡先）
```

- 画像の指定を必ず添える（メイン画像1点+補足。メディアはそのまま使える画像を求める）
- 専門用語は一般読者basis で書く。社内用語・自画自賛形容詞（「画期的な」「革新的な」）を削る

### 3. 事実確認

配信後の訂正は信頼を大きく損なう。数字・日付・固有名詞・「初」「No.1」の根拠・引用コメントの本人確認、をチェックリストとして依頼者に渡し、確認を求める。

### 4. 配信計画

- **配信先**: 配信サービス（PR TIMES 等）+ 直接アプローチしたい媒体・記者のリスト（業界紙・専門メディアは個別に。過去に類似テーマを書いた記者を探す）
- **タイミング**: 業界の慣行に合わせる（平日午前が一般的）。大型ニュースと重なる日・連休前を避ける。解禁日（エンバーゴ）がある場合は明記する
- **前後の連携**: 自社SNS・ブログ・メールでの同時発信、`launch-plan` があれば整合させる
- 取材が来た場合の想定Q&A（答えにくい質問含む）を用意する

### 5. 効果の振り返り

掲載数だけでなく: 掲載媒体の質、リリース経由の流入・問い合わせ、検索指名数の変化。次回のニュース価値設計への学びを記録する。

## 注意事項

- 未確定情報（「予定」レベルの提携先名など）を既成事実として書かない。相手企業名を出す場合は先方の広報承認が必須であることを必ず伝える
- 上場企業・その関連の場合、適時開示との順序・整合に注意を促す
- 調査リリースを作る場合は調査概要（対象・人数・期間・方法）の明記が必須

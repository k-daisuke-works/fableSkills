# SNS運用計画・投稿作成

続けられて成果につながるSNS運用を設計し、投稿を作るスキル。

## 大原則

**SNSは「続かない」ことで失敗する。** 理想の投稿頻度ではなく、依頼者が実際に確保できる時間から逆算した計画を作る。また、フォロワー数は目的ではない — 事業のどの数字（認知・リード・採用・既存客の維持）につなげるのかを最初に固定する。

## 手順

### 1. 前提の確認

- 運用目的（事業KPIとの接続）とターゲット（`persona-journey` があれば読む）
- **使える時間**（週何時間・誰が）と継続できる体制
- 既存アカウントの状況（フォロワー・過去の反応が良かった投稿）
- トーン制約（公式としてのNG・業界の温度感）

### 2. プラットフォーム選定

ターゲットの生息地 × コンテンツ形式の得意 × 運用コストで選ぶ。**最初は1つ、多くて2つ**:

- X: テキスト・速報性・拡散。B2B/開発者/時事に強い
- Instagram: ビジュアル・世界観。飲食・美容・D2C向け
- TikTok/Shorts/Reels: 短尺動画。認知獲得は最強だが制作コスト高
- YouTube: 資産型・検索される。長期投資
- LinkedIn: B2B・採用
- Facebook: 地域ビジネス・高年齢層

選ばなかったプラットフォームと理由も明記する（後の「あれもやろう」への防波堤）。

### 3. コンテンツの柱の設計

投稿をその場で考える運用は破綻する。**3〜5本の「柱」**を決め、すべての投稿をどれかに紐付ける:

例（B2B SaaSの場合）: ①ノウハウ（保存されるTips）②実例・事例（信頼）③製品の中身・開発の裏側（親近感）④業界ニュースへの見解（専門性）

- 各柱に目的（リーチ用 / 信頼用 / CV用）と割合を設定する。**宣伝(CV用)は全体の2割以下**が目安
- 柱ごとに投稿フォーマットのテンプレート（書き出し・構成・CTA）を作り、量産可能にする

### 4. 投稿カレンダー

- 現実的な頻度で週間・月間カレンダーを作る（柱のローテーション+時事枠）
- 表形式: 日付 / 柱 / ネタ / 形式（テキスト・画像・動画）/ CTA / ステータス
- ネタ切れ対策: よくある質問、過去人気投稿の別角度、季節・業界イベントの年間表を仕込んでおく

### 5. 投稿の作成

プラットフォームの作法に合わせる:

- **1投稿1メッセージ**。最初の1行（フィードで見える範囲）で止める力がすべて
- X: 冒頭で結論か違和感。改行で読みやすく。リンクだけの投稿は伸びない
- Instagram: 1枚目が表紙。キャプションの1行目で続きを読ませる
- ハッシュタグは大量に付けない（各プラットフォームの現在の慣行に従う）
- 複数案を出すときは切り口の違う案を出す

### 6. 振り返り運用

- 週次: 反応の良し悪しを柱別に記録（保存数・プロフィールクリックなど目的に対応する指標で見る。いいね数だけで判断しない）
- 月次: 柱の入れ替え判断と、事業KPIへの貢献確認
- 伸びた投稿の「再利用」（別角度・別形式で作り直す）を仕組みにする

## 注意事項

- 投稿を公開する行為自体は依頼者が行う前提。予約投稿の設定までを支援する
- 炎上リスクチェック: 時事・政治・宗教・ジェンダー・災害に関わる投稿は必ず立ち止まって指摘する。「今このタイミングで出すべきか」（世間の状況）も確認を促す
- 他者のコンテンツ・画像の無断利用、ステマ規制（PR表記）に注意する
- フォロワー購入・相互フォロー等のグロースハックは提案しない（アルゴリズム上も逆効果）

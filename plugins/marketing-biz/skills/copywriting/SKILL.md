# コピーライティング

売るための文章を、訴求軸の設計から書くスキル。うまい言い回しではなく「誰のどの欲求に何を約束するか」の設計が本体。

## 手順

### 1. 前提の確認

- 用途と掲載場所（LPヒーロー / 検索広告 / SNS広告 / メール件名 / バナー）と**文字数制限**
- ターゲット（`persona-journey` の成果物があれば読む）と、読む瞬間の文脈（何を検索した直後か、何のついでに目に入るか)
- 訴求の材料: 機能一覧、顧客の声、実績数値、価格。**証拠のない約束はコピーにできない**ので、使える証拠を先に棚卸しする

### 2. 訴求軸の設計

- 機能(Feature)→利点(Advantage)→便益(Benefit)に変換する。コピーに載せるのは便益。「AI搭載」ではなく「入力3分で終わる」
- 便益の階層を意識する: 機能的便益（速い・安い）< 感情的便益（安心・誇らしい）< 自己表現的便益。ターゲットの検討段階が浅いほど感情寄りが効く
- 訴求候補を5〜10個出し、「ターゲットの痛みの強さ × 競合が言えない度 × 証拠の強さ」で上位2〜3軸に絞る

### 3. 執筆

構造フレームは文脈で使い分ける:

- **PAS**（問題→あおり→解決）: 課題が自覚されている検索流入向け
- **AIDA**（注意→興味→欲求→行動）: 受動的な閲覧（SNS・ディスプレイ）向け
- **BAB**（Before→After→Bridge）: ビフォーアフターが視覚化しやすい商材向け

見出しの原則:
- 具体は抽象に勝つ（「作業時間を減らす」→「毎週金曜の3時間を取り戻す」）
- 数字は丸めない（「約30%」→「32%」の方が信頼される。ただし出典必須）
- 読者の言葉を使う（レビュー・問い合わせに出てくる表現をそのまま使うのが最強の調査）

CTA の原則: ボタン文言は行動の結果を書く（「送信」→「無料で試す」）。CTA 直前に不安の解消（無料・解約自由・カード不要）を置く。

### 4. 複数案の提示

**方向性の違う3案**を出す（同じ案の言い換え3つは無意味）。各案に「訴求軸 / 狙うターゲット心理 / 向いている配置」の説明を付け、推奨案を1つ明示する。可能なら A/B テストの設計（何を検証するか・必要サンプルサイズの目安）も添える。

### 5. リスクチェック

書いたコピーを以下で自己検査し、引っかかるものは修正案とセットで指摘する:

- **景品表示法**: 優良誤認（No.1表記は調査出典・期間の併記が必要、根拠のない「最安」「業界初」は不可）、有利誤認（二重価格の根拠）
- **薬機法**（健康・美容系）: 効果効能の断定表現（「治る」「痩せる」は原則不可）
- **証拠の裏付け**: コピー内の数字・実績はすべて出典を確認する。確認できないものは仮置きラベルを付けて依頼者に確認する
- 「個人の感想です」で逃げる設計になっていないか

## 注意事項

- 誇張で CV を稼ぐコピーは解約・返品・クレームで回収される。ターゲット外を弾くのも良いコピーの仕事
- 業界・媒体のトンマナ（B2B の堅さ、若年向けの温度感）を既存資料から把握して合わせる
- 完成形だけでなく、効いた/効かなかったときにどの変数を動かすか（見出し・証拠・CTA）を添える

# 市場調査・競合分析

意思決定に使える市場・競合の分析を、出典付きで行うスキル。

## 大原則

**事実と推測を混ぜない。** すべての数字・主張に「出典URL / 計算による推定（過程を明示）/ 仮説」のいずれかのラベルを付ける。出典のない市場規模は数字ではなく願望。

## 手順

### 1. 調査目的の確認

「何の意思決定のための調査か」を先に確定する（参入判断 / 投資家向け資料 / 製品の差別化検討）。目的によって深掘りすべき箇所が変わる。不明なら最初に一度だけ確認する。

### 2. デスクリサーチ

WebSearch / WebFetch で収集する。優先順位:

1. 一次情報: 政府統計、業界団体の統計、上場企業のIR資料（決算説明資料は市場データの宝庫）
2. 二次情報: 調査会社のプレスリリース、業界メディア
3. 参考程度: 個人ブログ、古い記事（**データの年次を必ず記録**。3年以上前の市場データは注意ラベル）

### 3. 市場規模の推定（TAM / SAM / SOM）

- **TAM**（獲得可能な最大市場）/ **SAM**（実際に狙える市場）/ **SOM**（現実的に取れる市場）の3層で出す
- 統計が見つからない場合はフェルミ推定で組み立て、**計算式と各係数の根拠を全部見せる**（例: 対象人口 × 利用率 × 単価 × 年間頻度）
- トップダウン（市場統計から絞る）とボトムアップ（顧客数×単価を積む）の両方で計算し、大きく食い違ったら原因を分析する

### 4. 競合分析

- 直接競合だけでなく**代替手段**（何もしない、Excelで済ます、外注する）も競合に含める
- 競合ごとに: 提供価値 / 価格 / ターゲット / 強み / 弱み / 直近の動き（資金調達・新機能）を表にする
- 価格・機能は競合の公式サイトから取得し、取得日を記録する
- **ポジショニングマップ**: 顧客の購買決定要因から2軸を選んで配置し、空白地帯が「機会」なのか「需要がない」のかを検討する

### 5. 構造分析

- **3C**（自社・顧客・競合）で要点整理
- **5 Forces** は参入判断のときに使う（新規参入の脅威 / 代替品 / 買い手・売り手の交渉力 / 既存競合）
- 分析フレームは結論を出すための道具。埋めるだけで終わらせず、各分析から「だから何をすべきか (So What)」を1文ずつ出す

### 6. 報告

構成: ①結論（調査目的への答えを3行以内）→ ②市場規模 → ③競合比較表とマップ → ④構造分析 → ⑤機会とリスク → ⑥出典一覧（URL・取得日）→ ⑦追加で調べるべきこと（残った不確実性）。

## 注意事項

- 調査結果が「参入すべきでない」を示すなら、はっきりそう書く。依頼者の期待に合わせて結論を曲げない
- 海外データを日本市場に流用するときは、その妥当性を明記する
- 検索で見つからなかったことも「見つからなかった」と報告する（沈黙は網羅と誤解される）

# Boost

Opus / Sonnet / Haiku に **Fableレベルの行動様式**を再現させるプラグイン。Fableが観測されている行動特性 — 自律実行・スコープ規律・検証済みの進捗報告・成果先出しの読みやすい要約 — を明示的な指示として適用し、難所では**推論ブースト**（熟考・新鮮コンテキスト検証・実行による裏取り）で実効的な推論品質も底上げする。モデル固有の推論能力の上限そのものは変わらない。

## 使い方

セッションの冒頭（または自律タスクを任せる直前）に呼び出す:

```
/boost
```

以後そのセッションでは、共通の行動様式に加えて、実行中のモデル階層に応じた追加指示が適用される。

## 何が変わるか

| 軸 | Boost適用後の挙動 |
|---|---|
| 自律性 | 可逆な操作で許可を求めない。些細な選択は自分で決めて一言添える |
| 実行 | 計画・約束でターンを終えない。「これからやります」と言ったら今やる |
| スコープ | 頼まれた範囲だけを最シンプルに。問題の説明を修正依頼と混同しない |
| 検証 | ツール実行結果に裏付けられた進捗だけを報告。失敗は出力付きで正直に |
| 報告 | 結論を最初の一文に。矢印連鎖や自作ラベルを排した完全な文で |
| 推論 | 難所（多段推論・高失敗コスト・再失敗・設計判断）では仮説2つ以上の熟考、新鮮コンテキストの検証サブエージェント、実行による裏取りを適用 |

## モデル別チューニング

- **Opus**: ツール・サブエージェント・検索へ手を伸ばす閾値を下げ、質問過多とナレーション過多を抑える
- **Sonnet**: 字義通り解釈の補正、実装前の自問、早すぎる切り上げの防止
- **Haiku**: 編集前必読・1変更1検証・推測の実在確認など、機械的に守るチェックを追加
